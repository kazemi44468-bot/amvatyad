# اموات یاد

وب‌سایت فارسی راست‌چین برای بزرگداشت یاد درگذشتگان، ثبت خاطرات، ساخت پیش‌نویس یادمان و معرفی کارهای خیر.

## صفحه‌ها
- `index.html`: صفحه اصلی
- `pages/services.html`: خدمات یادبود
- `pages/memorials.html`: یادمان‌ها
- `pages/stories.html`: دفتر خاطرات و روایت زندگی
- `pages/calendar.html`: تقویم یادبود
- `pages/charity.html`: خیرات و کارهای نیک
- `pages/about.html`: درباره اموات یاد
- `pages/contact.html`: تماس با ما

## تصاویر محلی
عکس‌های واقعی و تصویرسازی‌های برداری در پوشه `images/` قرار دارند. عکس‌ها به‌صورت فایل محلی نمایش داده می‌شوند و برای بارگذاری تصویر به CDN خارجی وابسته نیستند:
- `memorial-roses.svg`: گل سپید و فضای روشن یادبود
- `memorial-bouquet.svg`: دسته‌گل یادبود
- `memorial-candle.svg`: شمع و نور گرم
- `memorial-garden.svg`: باغ آرام و مسیر سبز
- `soft-landscape.svg`: منظره طبیعت با رنگ‌های آرام
- `logo-amvatyad.svg`: نشان اختصاصی سایت

عکس‌های عکاسی‌شده در فایل‌های JPG و تصویرسازی‌های تزئینی در فایل‌های SVG نگهداری می‌شوند.

## ساختار فنی
- `assets/css/style.css`: طراحی پایه، صفحه اصلی و پس‌زمینه‌های تصویری
- `assets/css/pages.css`: چیدمان و پس‌زمینه صفحه‌های داخلی
- `assets/js/main.js`: منوی موبایل و ذخیره محلی پیش‌نویس‌ها
- `assets/fonts/`: فونت‌های محلی پروژه

## نکته فنی
این نسخه برای میزبانی ایستا مانند GitHub Pages ساخته شده است. پیش‌نویس یادمان و خاطرات در localStorage همان مرورگر ذخیره می‌شوند و هنوز حساب کاربری، انتشار عمومی یادمان‌ها، بارگذاری عکس و یادآوری خودکار سمت سرور پیاده‌سازی نشده است.
