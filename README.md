# اموات یاد

وب‌سایت فارسی راست‌چین برای بزرگداشت یاد درگذشتگان، ثبت خاطرات، ساخت پیش‌نویس یادمان و پیشنهاد کارهای خیر.

## ساختار
- `index.html`: صفحه اصلی و بخش‌های خدمات، یادمان‌ها، مناسبت‌ها، کار خیر، دفتر خاطرات و فرم ساخت یادمان
- `assets/css/style.css`: طراحی واکنش‌گرا و رنگ‌بندی سبز آرام، کرم و طلایی
- `assets/js/main.js`: منوی موبایل، ذخیره محلی پیش‌نویس یادمان‌ها و خاطرات
- `images/`: نشان و تصویرسازی‌های محلی SVG
- `assets/fonts/`: فونت‌های محلی Vazirmatn موجود در مخزن

## نکته فنی مهم
این نسخه برای میزبانی ایستا مانند GitHub Pages ساخته شده است. فرم‌ها اطلاعات را به سرور ارسال نمی‌کنند؛ پیش‌نویس‌ها و خاطرات در localStorage همان مرورگر ذخیره می‌شوند. برای حساب کاربری، اشتراک‌گذاری عمومی یادمان‌ها، بارگذاری عکس، یادآوری مناسبت‌ها یا دریافت کمک مالی باید بعداً سرویس سمت سرور و کنترل‌های حریم خصوصی اضافه شود.

## تصاویر
نشان و تصاویر SVG داخل مخزن و به‌صورت محلی ذخیره شده‌اند. به دلیل محدودیت دسترسی شبکه در محیط اجرا، عکس‌های عکاسی‌شده از اینترنت در این مرحله دانلود و در مخزن ذخیره نشدند؛ تصویرسازی‌های برداری به‌عنوان جایگزین موقت استفاده شده‌اند.
