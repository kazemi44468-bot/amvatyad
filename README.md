# اموات یاد

وب‌سایت فارسی راست‌چین برای بزرگداشت یاد درگذشتگان، ثبت خاطرات، ساخت پیش‌نویس یادمان و معرفی کارهای خیر.

## صفحات سایت
- `index.html`: صفحه اصلی
- `pages/services.html`: خدمات یادبود
- `pages/memorials.html`: یادمان‌ها
- `pages/stories.html`: دفتر خاطرات و روایت زندگی
- `pages/calendar.html`: تقویم یادبود
- `pages/charity.html`: خیرات و کارهای نیک
- `pages/about.html`: درباره اموات یاد
- `pages/contact.html`: تماس با ما
- `404.html`: صفحه خطا

## ساختار فنی
- `assets/css/style.css`: طراحی پایه و واکنش‌گرا
- `assets/css/pages.css`: چیدمان صفحه‌های داخلی
- `assets/js/main.js`: منوی موبایل و ذخیره محلی پیش‌نویس یادمان‌ها و خاطرات
- `images/`: نشان اختصاصی و تصویرسازی‌های برداری
- `assets/fonts/`: فونت‌های محلی پروژه

## نکته فنی
این نسخه برای میزبانی ایستا مانند GitHub Pages ساخته شده است. فرم‌ها اطلاعات را به سرور ارسال نمی‌کنند؛ پیش‌نویس‌ها و خاطرات در localStorage همان مرورگر ذخیره می‌شوند. حساب کاربری، اشتراک‌گذاری عمومی یادمان‌ها، بارگذاری عکس، یادآوری خودکار مناسبت‌ها و دریافت کمک مالی هنوز پیاده‌سازی نشده‌اند.

## عکس‌های عکاسی‌شده
برای تکمیل ظاهر سایت، عکس‌های واقعی از Unsplash در حال حاضر از طریق نشانی اینترنتی نمایش داده می‌شوند. فایل‌های اصلی عکس هنوز به‌صورت محلی در پوشه `images/` ذخیره نشده‌اند؛ فهرست نشانی‌ها در `images/PHOTO-SOURCES.md` است.
