# وضعیت عکس‌ها

تصاویر استفاده‌شده در نسخه فعلی به‌صورت فایل‌های SVG محلی داخل همین پوشه قرار دارند و دیگر به نشانی اینترنتی تصاویر وابسته نیستند. این تصاویر، تصویرسازی برداری هستند نه عکس عکاسی‌شده. برای استفاده از عکس‌های واقعی، باید فایل‌های عکس جداگانه به پوشه `images/` افزوده و مسیر آن‌ها در HTML و CSS تنظیم شود.
