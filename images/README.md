# تصاویر محلی اموات یاد

این پوشه اکنون شامل نشان سایت و پنج تصویرسازی برداری SVG است که مستقیماً در صفحه اصلی، صفحه‌های داخلی و پس‌زمینه‌های CSS استفاده می‌شوند.

- `logo-amvatyad.svg`: نشان سایت
- `memorial-roses.svg`: گل‌های سپید و نور نرم
- `memorial-bouquet.svg`: دسته‌گل
- `memorial-candle.svg`: شمع روشن
- `memorial-garden.svg`: باغ و مسیر آرام
- `soft-landscape.svg`: منظره طبیعت

همه فایل‌ها محلی هستند؛ تصاویر برای نمایش به سرویس خارجی نیاز ندارند. این فایل‌ها تصویرسازی‌اند و عکس واقعی محسوب نمی‌شوند.
