# پوشه تصاویر اموات یاد

- `logo-amvatyad.svg`: نشان اختصاصی برداری اموات یاد.
- `hero-remembrance.svg`: تصویرسازی برداری گل سپید.
- `flowers.svg`, `nature.svg`, `candle.svg`: تصویرسازی‌های برداری محلی.
- `PHOTO-SOURCES.md`: منابع عکس‌های عکاسی‌شده‌ای که در صفحه‌های سایت نمایش داده می‌شوند.

عکس‌های واقعی در حال حاضر با نشانی مستقیم از منبع نمایش داده می‌شوند و هنوز فایل باینری آن‌ها در این پوشه ذخیره نشده است.
