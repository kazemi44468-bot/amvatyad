# تصاویر اموات یاد

- `logo-amvatyad.svg`: نشان اختصاصی برداری اموات یاد؛ شعله، برگ و هاله طلایی نماد یاد روشن و مهربانی ماندگار.
- `hero-remembrance.svg`: تصویرسازی اختصاصی گل سپید برای بخش آغازین.
- `flowers.svg`, `nature.svg`, `candle.svg`: تصویرسازی‌های برداری محلی برای کارت‌های یادبود.

این تصاویر در خود مخزن ذخیره شده‌اند و به سرویس تصویر خارجی وابسته نیستند. در این مرحله، امکان دریافت و ذخیره فایل‌های عکاسی اینترنتی در محیط اجرا فراهم نشد؛ بنابراین از تصویرسازی‌های برداری اختصاصی استفاده شده است و آن‌ها را به‌عنوان عکس واقعی معرفی نمی‌کنیم. برای انتشار عمومی، می‌توان این تصویرسازی‌ها را با عکس‌های واقعی دارای مجوز مناسب جایگزین کرد.
