# تصاویر محلی اموات‌یاد

این پوشه شامل عکس‌های عکاسی‌شده و تصویرسازی‌های برداری است. عکس‌های JPG در صفحات اصلی و خدمات به‌کار رفته‌اند و فایل‌های SVG برای هویت بصری و عناصر تزئینی استفاده می‌شوند.

## عکس‌های عکاسی‌شده
- `memorial-garden.jpg`: تصویر باغ آرام برای بخش معرفی و صفحه فرایند
- `memorial-bouquet.jpg`: گل‌آرایی یادبود برای بخش‌های تصویری صفحه اصلی و خدمات
- `memorial-roses.jpg`: تصویر گل‌های رز برای کارت گنجینه خاطرات
- `memorial-candle.jpg`: شمع یادبود برای کارت ادای احترام

## نشان و تصویرسازی‌ها
- `logo-amvatyad.svg`: نشان اصلی وب‌سایت و favicon
- `logo.png`: نسخه تصویری نشان
- `hero-remembrance.svg`, `memorial-roses.svg`, `memorial-bouquet.svg`, `memorial-candle.svg`, `memorial-garden.svg`, `soft-landscape.svg`, `nature.svg`, `flowers.svg`, `candle.svg`: تصویرسازی‌های برداری برای استفاده‌های تکمیلی

تمام مسیرهای مورد استفاده در وب‌سایت محلی‌اند و برای نمایش به CDN تصاویر وابسته نیستند. پیش از انتشار نهایی، اطلاعات منبع و مجوز هر عکس باید در فایل `PHOTO-SOURCES.md` تکمیل شود؛ نگهداری فایل در مخزن به‌تنهایی به معنی تأیید مجوز انتشار نیست.
