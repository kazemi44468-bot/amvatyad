# تصاویر و رسانه‌های اموات یاد

فایل‌های عکس در این پوشه به‌صورت محلی ذخیره شده‌اند تا صفحات وب‌سایت برای نمایش تصاویر به CDN بیرونی وابسته نباشند.

## عکس‌های عکاسی‌شده
- `memorial-garden.jpg`: تصویر طبیعت برای بخش معرفی و فرایند
- `memorial-bouquet.jpg`: گل‌ها برای بخش خدمات و کارت‌های تصویری
- `memorial-roses.jpg`: گل‌های رز برای گنجینه خاطرات
- `memorial-candle.jpg`: عکس شمع یادبود؛ منبع دقیق این فایل قدیمی هنوز نیازمند بررسی است
- `soft-landscape.jpg`: چشم‌انداز طبیعی

منابع و وضعیت مجوز عکس‌ها در [PHOTO-SOURCES.md](PHOTO-SOURCES.md) ثبت شده‌اند.
